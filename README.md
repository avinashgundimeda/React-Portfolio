# React Portfolio

A modern, fully responsive portfolio website built with React and Tailwind CSS. Showcasing cybersecurity projects, development experience, and technical skills with a sleek dark mode interface.

## 🚀 Live Demo

**[View Portfolio](https://avinashgundimeda.vercel.app/)**

## ✨ Features

- **Dark Mode Toggle** - Seamless light/dark theme switching
- **Responsive Design** - Fully optimized for mobile, tablet, and desktop
- **Modern UI** - Clean, minimalist design using Tailwind CSS
- **Project Showcase** - Highlights of cybersecurity and full-stack projects
- **Smooth Animations** - Interactive elements and page transitions
- **Contact Integration** - Easy ways to reach out and connect
- **SEO Optimized** - Meta tags and structured data for better discoverability

## 🛠️ Tech Stack

- **Frontend Framework** - React (with Vite)
- **Styling** - Tailwind CSS
- **Build Tool** - Vite
- **Deployment** - Vercel
- **Configuration** - PostCSS, ESLint

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/avinashgundimeda/React-Portfolio.git
   cd React-Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```
